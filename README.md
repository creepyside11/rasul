# 🤖 Telegram Spammer & Broadcast Bot (aiogram 3 + Telethon + PostgreSQL)

Асинхронный Telegram-бот для управления аккаунтами и гибкой рассылки сообщений по группам и каналам. Написан на **aiogram 3** (для интерфейса бота) и **Telethon** (для работы с аккаунтами Telegram), с постоянным хранилищем сессий и задач в **PostgreSQL**.

---

## ⚡ Особенности и возможности

- **📱 Менеджер аккаунтов**:
  - Быстрое добавление Telegram-аккаунтов прямо через бота (ввод номера телефона и кода подтверждения).
  - Поддержка облачного пароля (**2FA / Двухфакторная аутентификация**).
  - Безопасное хранение авторизаций: все сессии сохраняются как `StringSession` в PostgreSQL (нет мусора из десятков `.session` файлов).
  - Просмотр списка подключенных аккаунтов со статусами и их удаление в один клик.

- **🚀 Функции рассылки**:
  - **Выбор чатов**: от 1 до 100 доступных диалогов с выбранного аккаунта.
  - **Задержка**: настраиваемый интервал между отправками в секундах (поддерживаются дробные значения: `0.5`, `1.5`, `3` и т.д.).
  - **Количество сообщений**: точный лимит сообщений в каждый выбранный чат.
  - **Режимы рассылки**:
    - 🎲 **Рандомный (по 1)** — отправка по очереди в случайно выбираемые чаты из списка.
    - ⚡ **Одновременный** — параллельная одновременная отправка во все чаты сразу.
  - **Контент сообщений**:
    - Полная поддержка **HTML-разметки** (жирный, курсив, ссылки, цитаты, код).
    - Поддержка отправки **фотографий с текстом** или обычных текстовых сообщений.
  - **FloodWait-защита**: авто-пауза при временных ограничениях со стороны Telegram.

- **📊 Мои рассылки**:
  - Просмотр запущенных и завершённых рассылок.
  - Кнопка **🛑 Мгновенной остановки** любой активной рассылки.

## ⚙️ Переменные окружения (Environment Variables)

Все настройки читаются из системных переменных окружения или из файла `.env`:

| Переменная | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен управления ботом от [@BotFather](https://t.me/BotFather) | `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11` |
| `ADMIN_ID` | Ваш цифровой Telegram ID (кому разрешен доступ к боту) | `123456789` |
| `API_ID` | Telegram API ID приложения (брать с [my.telegram.org](https://my.telegram.org)) | `12345678` |
| `API_HASH` | Telegram API Hash (брать с [my.telegram.org](https://my.telegram.org)) | `abcdef0123456789abcdef0123456789` |
| `DATABASE_URL` | Строка подключения к PostgreSQL (asyncpg) | `postgresql+asyncpg://postgres:postgres@localhost:5432/bot_broadcast` |

## 🚀 Развертывание и запуск

### Способ 1: Запуск через Docker & Docker Compose (Рекомендуемый)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/creepyside11/rasul.git
   cd rasul
   ```

2. Создайте файл `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```
   и заполните свои значения (`BOT_TOKEN`, `ADMIN_ID`, `API_ID`, `API_HASH`).

3. Запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```
   PostgreSQL и Бот запустятся в фоновом режиме. База данных и таблицы создадутся автоматически.

4. Просмотр логов:
   ```bash
   docker compose logs -f bot
   ```

---

### Способ 2: Запуск без Docker (на VPS / сервере / виртуальном окружении)

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com/creepyside11/rasul.git
   cd rasul
   ```

2. Установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Задайте переменные окружения через `.env` или экспорт:
   ```bash
   export BOT_TOKEN="ваш_токен"
   export ADMIN_ID=123456789
   export API_ID=12345678
   export API_HASH="ваш_хэш"
   export DATABASE_URL="postgresql+asyncpg://user:pass@localhost:5432/bot_broadcast"
   ```

4. Запустите бота:
   ```bash
   python3 main.py
   ```
